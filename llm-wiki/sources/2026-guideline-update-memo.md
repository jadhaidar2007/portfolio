Subject: NIG guideline update — AI tools and cloud costs now eligible

From: Program Office North
Date: 2026-11-03

Starting with the 2027 call, two changes apply to the Nordlicht Innovation Grant:

1. Cloud computing and AI API costs used directly for the R&D project are eligible
   costs, capped at 15% of total eligible costs.
2. Projects that deploy an AI system in production must attach a short risk
   assessment to the full proposal (data used, human oversight, failure modes).

All other rules stay unchanged. Questions go to the grants-management team.
